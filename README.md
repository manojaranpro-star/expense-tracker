# 💰 Expense Tracker

A simple, clean, and mobile-friendly **Expense Tracker website** built with HTML, CSS, and JavaScript.

It helps you track your income, expenses, balance, categories, and monthly spending directly in your browser.

## ✨ Features

- 💰 Current balance
- 📈 Total income
- 📉 Total expenses
- ➕ Add income and expense transactions
- 🏷️ Expense and income categories
- 📅 Transaction dates
- 🔎 Search transactions
- 🔽 Filter by type
- 🔽 Filter by category
- 🗑️ Delete transactions
- 📊 6-month expense overview chart
- 💾 Automatically saves data in browser Local Storage
- 📱 Responsive design for mobile, tablet, and desktop
- 🇮🇳 Indian Rupee (₹) currency formatting
- 🚫 No database required
- 🚫 No account or login required
- ⚡ Works as a single HTML file

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- HTML Canvas

## 🚀 How to Use

### 1. Download or Clone the Project

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/expense-tracker.git
```

Open the project folder:

```bash
cd expense-tracker
```

### 2. Open the Website

Simply open:

```text
index.html
```

in Google Chrome, Microsoft Edge, Firefox, or another modern browser.

No installation is required.

## 💾 Data Storage

The Expense Tracker stores transactions using your browser's **Local Storage**.

This means:

- Your transactions stay in your browser.
- No database is required.
- No server is required.
- The website can work offline after loading.
- Clearing your browser's site data may remove your saved transactions.

## 📊 Dashboard

The dashboard displays:

| Section | Description |
|---|---|
| Current Balance | Income minus expenses |
| Total Income | Total recorded income |
| Total Expense | Total recorded expenses |
| Transactions | List of recorded transactions |
| Expense Overview | Expense activity over the last 6 months |

## 🌐 GitHub Pages

You can publish this project for free using **GitHub Pages**.

### Steps

1. Create a GitHub repository.
2. Upload `index.html`.
3. Upload `README.md`.
4. Go to:

```text
Settings → Pages
```

5. Under **Build and deployment**, select:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

6. Click **Save**.

Your website will be available at:

```text
https://YOUR-USERNAME.github.io/expense-tracker/
```

Replace `YOUR-USERNAME` with your GitHub username.
